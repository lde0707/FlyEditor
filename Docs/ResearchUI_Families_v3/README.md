# FlyEditor 계열별 증강 색상 v3

2026-11-04 · 최신 요청: 같은 계열은 같은 색을 사용하고 계열 간 색을 구분한다.

| 계열 | 기본 연구 | 형태 연계 | 전문화 | 색 |
|---|---|---|---|---|
| 속도 | A1·A2·A3 | X2 기수 가속 | P2 속도 전문화 | 파스텔 살구 |
| 활공 | G1·G2·G3 | X1 날개 활공, X3 기류 동조 | P1 활공 전문화 | 파스텔 하늘색 |
| 조종 | C1·C2·C3 | X4 민첩 제어 | — | 파스텔 라벤더 |
| 생존 | S1·S2·S3 | X5 안정 복원 | P3 안정 전문화 | 파스텔 세이지 |

교차 연구는 효과를 주는 주 계열의 색을 사용한다. 추가 선행 조건의 색을 섞지 않는다. 전체 선행 조건과 단계는 기존 노드 데이터 기준을 유지한다.

## 상태 규칙

- 후보: 흰 바탕 + 해당 계열의 선·심볼.
- 선택: 해당 계열의 이중 테두리 + 아주 연한 바탕.
- 강화: 체크 + 실제 단계 수만큼 채운 표시 + 연한 계열 바탕.
- 단계가 높아질수록 바탕색 농도가 조금 진해진다.
- 최대 단계도 파스텔 계열 바탕이며 검정 채움을 쓰지 않는다.
- 구매 버튼, 체크, 단계와 짧은 모서리 피드백도 선택한 증강 계열 색을 따른다.
- 흰 배경, 각진 형태, 네온·발광·그라데이션 없음.

## 개별 파일

- `Node_{ID}_Rank{n}.png`, `_Selected.png`: 전체 20개 증강의 실제 최대 단계 수에 맞춘 완성형 노드 114개.
- `Frame_{계열}_{모양}_{상태}.png`: 공용 프레임 72개. Square·Diamond·Hexagon × 상태 6개 × 계열 4개.
- `Icon_{ID}.png`: 계열색을 적용한 독립 심볼 20개.
- `Action_{계열}_{상태}.png`: 설명창 구매 버튼 16개.
- `Feedback_{계열}_{0~2}.png`: 구매 성공 피드백 12개.
- `Node_Root.png`: 중립색 중앙 시작점 1개.
- 합계 PNG 235개 + 동일한 SVG 235개. `.meta` 포함.

계열 파일명은 Speed / Glide / Control / Survival이다. 개별 심볼·공용 프레임 방식과 완성형 노드 방식을 중복으로 겹치지 않는다. 완성형에는 프레임·심볼·단계가 들어 있다.

## 보기

- `Previews/Family_Selection_Upgrade_States.png`: 계열별 선택·강화 상태 비교.
- `Previews/Full_Web_Families_1920x1080.png`: 20개 증강 전체를 보여주는 기획용 웹.
- 전체 보기는 기획용이다. 실제 플레이에서는 구매한 노드와 현재 후보만 표시한다.
- 현재 Unity에 기능이 구현된 연구는 A1·G1·C1 세 가지다. S1·고급 연구·전문화 그래픽 제공은 해당 기능의 구현 완료를 뜻하지 않는다.

## 적용

Unity 새 폴더: `Assets/_Project/UI/ResearchUI_Families_v3`.

PNG는 Sprite / Single / Full Rect / Alpha Is Transparency / Mipmap Off / 압축 없음이다. 노드 캔버스는 160×192px, 프레임 중심 (80,80)이다. 노드는 Image Type=Simple, Action 버튼은 512×96px에 14px Border로 Sliced를 사용한다.

텍스트는 별도 Unity 텍스트로 표시하며 해당 계열의 `dark` 색을 사용한다. 실제 색상 코드와 ID별 매핑, 최대 단계 수는 manifest.json에 있다. 색 외에도 모양·체크·단계를 유지한다.

기존 단색 민트 자산은 보존했다. 이번 작업은 기존 벡터 자산을 확장한 것으로 이미지 생성 도구를 추가 호출하지 않았다. UI 연결·실제 런타임 구매 로직은 변경하지 않았다. 생성 도구 재실행에는 형제 경로의 research-ui-v1과 research-ui-states-mint-v2가 필요하다.
