# FlyEditor — 줌 가능한 33개 1회 구매 연구 웹

2026-11-05. 기존 11종의 강화 단계를 33개의 독립 노드로 분리했다. 하나의 버튼을 세 번 구매하는 UI와 3칸 단계 표시는 제거했다.

## 조작

- 마우스 휠: 커서 아래 지점을 기준으로 확대/축소. 35~150%.
- 오른쪽 또는 가운데 버튼 드래그: 웹 이동.
- `-` / `+`: 화면 중심 기준으로 축소/확대.
- `전체 보기`: 현재 표시 가능한 노드들을 화면 안에 맞춘다.
- `100%`: 기본 배율과 중앙 위치로 돌아간다.
- 우측 상세창과 구매 버튼은 웹 줌에 영향을 받지 않는다.

## 1회 구매 규칙

- 노드마다 고유 ID와 하나의 가격을 갖는다. 구매하면 완료 체크와 보강 프레임으로 바뀌고 다시 구매할 수 없다.
- 이미 구매한 노드와 그다음 구매 가능한 후보만 표시한다. 연구점이 부족해도 후보는 보이되 구매만 비활성화한다.
- 후보가 아닌 노드와 그 연결선은 완전히 숨긴다.
- 새 능력을 처음 여는 노드만 큰 접힌 팔각 프레임이다. 해당 능력의 성능을 올리는 후속 노드는 작은 사각 프레임이다.
- 심볼과 노드는 정사각 원본이고 모든 배율에서 가로/세로를 동일하게 줄인다. 선택해도 크기는 변하지 않는다.

## 33개 구성

| 계열 | 기존 항목 | 각각 한 번씩 구매하는 노드 |
|---|---|---|
| 속도 | 던지기 강화 | 던지기 강화 → 힘 전달 → 긴 팔로스루 |
| 속도 | 표면 저항 감소 | 표면 저항 감소 → 매끈한 날개 → 공기 가르기 |
| 속도 | 가속 아이템 강화 | 가속 아이템 강화 → 추진력 집중 → 강한 추진 |
| 속도 | 하강 가속 | 하강 가속 해금 → 하강 전환 → 가속 유지 |
| 비행 | 활공 효율 | 활공 효율 → 날개 균형 → 장거리 활공 |
| 비행 | 상승 효율 | 상승 효율 → 부드러운 상승 → 고도 전환 |
| 조종 | 자세 회복 | 자세 회복 해금 → 빠른 복원 → 재정비 |
| 보호 | 기체 내구 | 기체 내구 → 동체 보강 → 접힘 보강 |
| 보호 | 충격 분산 | 충격 분산 → 완충 구조 → 속도 보호 |
| 보호 | 종이 방패 | 종이 방패 해금 → 방패 보강 → 예비 방패 |
| 수집 | 수집 끌어당김 | 수집 끌어당김 해금 → 넓은 수집 → 빠른 수집 |

실제 선행 연결은 `manifest.json` 및 `ResearchWeb.asset`에 기록했다. 시작점에서 던지기/활공/자세 회복/내구/수집 계열로 갈라지고, 던지기에서 저항과 가속 아이템, 가속 아이템에서 하강 가속으로 분기한다. 모든 노드가 3개씩 일렬로 이어지는 하나의 긴 경로는 아니다. 후속 능력의 세부 효과와 비용은 설계 초안이다.

## 현재 구현과 보류 기능

실제 구매와 비행 효과가 연결된 것은 던지기 3개와 활공 3개, 총 6개다. 처음에는 던지기 강화와 활공 효율 2개만 후보다. 나머지 27개는 해당 게임 기능을 구현하기 전까지 일반 플레이에서 숨긴다. 상승 기류를 포함한 보류 능력은 이 데이터에서 제외했다.

Play 중 비행 대기/착륙 상태에서 `Tools > FlyEditor > Preview Complete Research Web (Play Mode)`를 실행하면 33개 전체가 보이고 자동으로 줌 아웃한다. 전체 미리보기는 구매할 수 없으며 Esc로 나가면 일반 모드로 돌아온다.

## 기존 저장 호환

기존 `starter-research-v1.json`은 덮어쓰거나 초기화하지 않는다. 저장된 a1=2는 Launch_1과 Launch_2 구매 완료, Launch_3 후보로 해석한다. g1도 동일하다. 내부 누적값은 저장 호환과 비행 계산용으로 유지하며 화면과 구매는 독립 노드 기준이다. 기존 비용 30/65/130과 던지기 +3%씩, 활공 침하 -4%씩은 유지한다.

이전에 구매한 조종 반응(c1)은 효과와 기록을 보존하지만 이번 선택 목록에서 빠졌으므로 새 웹에서는 판매하지 않는다. 연구점 환급이나 저장 삭제는 수행하지 않는다.

## 구성 및 검증

- `Sprites/`: 정사각 노드/아이콘, 구매 버튼, 패널 등 PNG 186종과 Unity 메타.
- `Vectors/`: 동일 벡터 원본.
- `Previews/Dense_Web_33_Nodes_1920x1080.png`: 전체 설계 이미지. 실제 게임 화면 캡처와 구분한다.
- `manifest.json`: 노드 ID, 선행 조건, 개별 비용, 크기, 좌표, 구현 여부.
- `ResearchWeb.asset`: 씬이 기존 GUID로 참조하는 에셋에 적용할 새 데이터.
- 새 능력의 모든 후속 기능이 구현됐다는 의미가 아니다.

격리 Unity 프로젝트에서 저장 단계 0~3 대응, 재구매 금지, 다음 후보만 표시, 비용, 저장 실패 원자성, 실제 비행 반영, 커서 고정 줌, 확대/축소 제한, 이동 FSM, 전체 보기와 초기화, 기존 비행 Play 검사를 수행한다. 결과 로그와 실제 UI 확인 사항은 `verification.json`을 참조한다.

## 구매 후보 반투명 표시 (2026-11-05)

- 구매 전 후보 전체는 불투명도 50%로 표시한다. 선택과 구매 처리는 그대로 유지한다.
- 구매 완료한 노드는 100% 불투명으로 표시한다.
- 선택한 후보의 바깥 선택 표시는 선명하게 유지한다.
- 아직 선행 조건이 충족되지 않은 노드와 연결선은 일반 연구 화면에서 표시하지 않는다.
- 전체 설계 미리보기에는 '실제 구매 후보만 보기' 전환 버튼을 추가했다.
- 연구점 부족 여부는 우측 구매 버튼에서 별도로 처리한다.
- 격리 Unity 컴파일 및 기존 구매/저장/후보 표시/Play 검사 통과: unity-web-candidate-opacity.log, exit 0.
