# Unity 현재 작업 확인

확인일: 2026-11-04

## 실제 확인한 것

- Unity 6000.5.3f1에서 `InGame.unity`를 열어 Play를 시작하고 연구 화면까지 직접 확인했다. 구매·발사 입력 없이 확인 후 Play를 종료했다.
- 코드에는 `FlightModel`, `FlightResearch`, `FlightSession`, `PaperFlightController`가 있고 비행과 연구 화면을 구분한다.
- 연구 저장 모델은 Throw / Glide / Control 세 종류다. 각 3단계, 가격 30 / 65 / 130이며 첫 비행 완료 후 연구가 열린다.
- 연구점은 착륙한 비행의 최대 전방 거리 / 5를 내림해 지급한다. 실제 현재 저장 데이터로 보이는 연구점은 1이었다. 테스트 재화 추가나 구매는 하지 않았다.
- 연구 웹은 왼쪽 75%, 설명 패널은 오른쪽 약 25%다. 중앙 시작점과 사각형 연구 3개, 선택 이중 테두리와 단계 표식을 사용한다.
- 흰색 배경, 파스텔 기체·산 배경, 각진 연결선 방향이 이미 들어 있다.
- HP와 장애물 피해가 없는 현재 시제품에서 S1 내구 연구를 노출하지 않는 처리는 실제 기능 범위와 맞는다.

## 화면에서 보인 점

- 작은 Unity Game 뷰에서 패널 본문·가격·상태 글씨가 작게 보인다.
- 캡처에서 일부 선·글자·종이비행기 심볼이 끊겨 보이고 사선 흔적도 나타났다. 렌더링/디스플레이 캡처/스케일 중 무엇이 원인인지는 확정하지 않았다.
- Unity 상태바에는 `Deleting invalid font reference.` 경고가 표시됐다. 이것만으로 캡처 문제의 원인을 판단하지 않는다.
- UI는 IMGUI 직접 그리기 방식이다. 제공 PNG를 사용하려면 기존 OnGUI에 텍스처를 연결하거나 별도 Canvas UI로 옮겨야 한다.

## 이번 결과의 적용 범위

분리 PNG 43개가 Unity Project 창에 임포트된 것을 확인했다. 버튼을 선택해 Inspector에서 Sprite / Single / Full Rect / Alpha Is Transparency / Mipmap 비활성 설정을 직접 확인했다. 이 확인은 에셋 임포트에 대한 것이며 실제 UI 연결·9-slice 리사이즈 동작까지 실행한 것은 아니다.

현재 3종 배치와 향후 20종 전체 웹 시안을 각각 만들고, 버튼·배경·설명창·노드·아이콘을 분리했다. 기존 게임 로직과 저장 규칙을 바꾸지 않고 새 리소스 폴더만 추가한다. 신규 스크립트의 코드 리뷰·물리 밸런스 재검사·게임 전체 QA를 완료했다고 주장하지 않는다.
