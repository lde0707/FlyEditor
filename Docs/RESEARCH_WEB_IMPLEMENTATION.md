# 비행 연구 웹 구현

98개 노드를 한 번씩 구매하는 연구 웹이다. 첫 비행 정산 후 5개 후보가 열리며, 선행 노드 중 하나를 구매하면 다음 후보가 나타난다.

## 화면과 연결

- 새 능력 16개는 큰 육각형, 일반 강화는 사각형이다.
- 중앙 출발점은 가장 큰 청회색 팔각형이다. 구매나 선택 대상에서 제외한다.
- 144개 연결선은 노드와 동일한 다각형 외곽에서 시작하고 끝난다. 반투명 후보 내부에 선이 비치지 않도록 선의 두께도 외곽에서 자른다.
- 계열을 넘는 연결은 점선이다. 일반 모드에서는 구매한 선행 노드에서 열린 경로만 표시한다.
- 구매 전 후보 50%, 구매 후 100%. 잠긴 후보는 숨긴다.
- 마우스 휠로 25~150% 확대·축소, 오른쪽 또는 가운데 드래그로 이동한다. 전체 보기는 중앙과 모든 표시 노드를 여백 안에 맞춘다.

## 구매와 저장

- 기존 33개 노드 ID, 연구점, 비행 기록, 레거시 조종 강화 기록을 보존한다.
- 신규 65개도 실제 구매·효과에 연결되어 있다. 연구 설명창에서 용도와 효과 수치를 구분해 보여 준다.
- 연결선 여러 개가 들어오면 선행 노드 하나만 구매해도 열린다. 한 노드의 중복 구매는 거부한다.
- 신규 효과는 다음 비행의 설정에 반영한다. 모든 추가 연구점은 기본 거리 보상의 50%까지이며, 거리 보상과 함께 원자적으로 저장한다.
- 보상 저장 실패 시 재시도할 수 있으며 같은 비행을 두 번 정산하지 않는다.
- 개발자 모드의 포인트 증감, 포인트만 초기화, 전체 초기화 동작을 지원한다.

## 검증

Unity 6000.5.3f1 격리 프로젝트에서 컴파일, 정상 Play 구매·저장 복원, 기존 기록 복원, 모든 신규 효과 값 연결, 조건부 보호·회복·수거 효과, 보상 상한, 저장 실패 재시도, 전체 구매 시 비행 종료, 확대·축소를 검증한다.

## 기체 성장과 아이템

누적 구매 8·22·42·68·90개에서 발사 속도와 최고 속도가 각각 기본 등급의 1.45·2.45·3.8·5.2·6.5배가 된다. 상승 각도와 항력도 등급에 맞춰 조정한다. 모든 계열 구매가 등급에 포함된다.

가속 아이템은 2초간 수평 이동 속도를 높인다. 연속 수거는 가속량을 중첩하지 않고 지속 시간을 갱신한다. 거리 수리와 연구점 보상은 각각 비행 거리와 착륙 정산에서 처리한다.
