# 자유점 선택과 공통 모아 접기

2026-11-10 · Unity 6000.5.3f1

## 조작

- 기본 격자 점은 표시하지 않는다. 종이 위를 일반 클릭하면 그 위치에 점을 만든다. Alt 불필요.
- 첫 점 이후 두 번째 점을 선택하면 접는 축이 생긴다. 면 클릭으로 각도 조절, 선택된 끝점 드래그로 기존 접기/벌리기 동작을 이어간다.
- 두 번째 점은 선택한 종이 면 좌표계의 가로/세로에 약 4도 이내, UI 좌표 8픽셀 이내일 때만 정렬한다. 카메라 회전과 무관한 종이 기준이다. 범위 밖의 대각선은 보정하지 않는다.
- 종이의 실제 모서리 및 꼭짓점도 8픽셀 이내에서 맞춘다. 빈 공간에 점을 만들지 않는다.
- 선택한 점 재클릭: 그 점 해제. 빈 공간 클릭: 전체 선택 해제. 빈 공간/점이 없는 곳 드래그: 화면 이동. 이동은 점 생성으로 처리하지 않는다.
- 2점 뒤에는 면 클릭과 점 추가를 구분한다. **점 추가 [F]** 버튼/단축키로 세 번째·네 번째 점을 일반 클릭한다. 최종 점 개수로 2점/4점 접기를 판정한다.
- 겹 선택: 보이는 겹 / 다음 겹(Tab) / 전체 겹. 자유점도 선택한 겹의 표면에 귀속한다. 선택 해제 시 임시 점을 정리한다.
- 자유점 자체를 상시 격자로 저장하지 않는다. 적용된 접기의 축과 제어점 좌표를 기존 FoldStep에 저장해 재생한다.

## 공통 접기 연산

PaperRadialGather는 네 제어점의 기하 관계로 여덟 부채꼴 영역을 함께 모으는 연산이다. 도안 이름이나 도안별 좌표를 런타임에 넣지 않았다. 새로운 coordinatedCreases 플래그가 있는 입력에만 적용하므로 기존 저장 접기와 분리된다.

첫 90도는 면들을 세워 모으고, 다음 90도는 삼각형 형태로 눌러 편다. 각 영역은 강체 회전하며 원래 종이 좌표의 이음매를 검사한다. 전체 겹 선택일 때만 두 겹 이상의 패킷을 함께 움직인다. 펼쳐진 아래 몸통이 연결된 사각형에서도 위 패치만 모으는 동작을 검증했다.

자유점 오차는 네 점이 정사각형 접힘 관계에 반경의 2% 이내로 가까운 경우에만 호환 배치로 맞춘다. 큰 차이가 있는 배치를 임의로 바꾸지 않는다.

**물리적 한계:** 중립면의 강체 운동과 겹 순서를 계산하는 기하 모델이다. 유한 두께 종이의 접촉·마찰·변형 전체를 시뮬레이션하는 엔진은 아니다. 여덟 겹의 완전히 닫힌 부분은 표시 두께에 따른 이음매 간격이 발생한다. 검증에서 중립면 이음매 < 0.002, 표시 표면 최대 간격 약 0.063(8겹 두께 0.072 이내)을 별도로 확인했다. 기존 4겹용 표면 간격 검사 기준을 무작정 완화하지 않고, 8겹 사례를 중립면과 표시 두께로 분리 검사한다.

## 검증

- SurfacePointPlay: Unity Input System의 실제 마우스/키 입력으로 점 없는 시작, 일반 클릭, 가로/세로 정렬, 자유 대각선, 꼭짓점 맞춤, 재클릭 해제, 빈 공간 클릭, 이동 드래그, 자유 축 40도 접기, 저장 재생, 되돌리기, F 점 추가, 4점 모아 접기, E/C 수정, 아래 겹 점 선택을 검사한다. IMGUI 버튼은 같은 AddMorePoints 동작에 연결되며, 자동 입력에서는 F 경로를 사용한다.
- RadialGatherVerification: 회전 4가지 × 양옆 순서 2가지 × 방향 2가지 = 16가지, 중간/최종 각도, 역방향 스크럽, 면적·이음매, 부분 저장 재생, 되돌리기, 두 겹 패킷과 아래 몸통 보존, 선택 범위, 기존 저장 플래그를 검사한다.
- 기존 Petal/Pocket/FourPoint/PaperFolding 회귀 검사 수행. 기존 기체 모양, 잡는 위치, 성능 측정 검사 포함.
- 테스트용 Input harness는 Docs에 보관하며 게임 런타임에는 포함하지 않는다. 테스트의 초기 상태 준비는 API로, 조작 검사는 Input System으로 수행한다.
