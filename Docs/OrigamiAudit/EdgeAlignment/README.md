# 변 → 기준선 맞추기 — 2026-11-12

## 조작

상단 `변 맞추기 [M]` → 옮길 변 클릭 → 맞출 중앙선/변 클릭 → `C`.
접는 선의 위치를 직접 찍거나 네 개의 점을 순서대로 지정하지 않아도 된다.
C 대신 면 드래그/각도 슬라이더로 부분 접기도 가능하다.

- 갈색: 옮길 변
- 파란색: 목표 기준선
- 초록색: 실제 움직일 면
- Esc/M: 취소. 기준선 선택 중 Backspace: 옮길 변부터 다시 선택.
- 뒤쪽 면은 그대로 선택하지 않는다. B 또는 키패드 반대 시점으로 뒤집어서 선택한다.
- 목표 중앙선이 여러 조각이면 같은 직선 위의 보이는 구간을 클릭해도 된다.
- 목표는 선분 길이가 아닌 그 선분이 놓인 기준 직선이다.
- 서로 다른 평면에 있는 변이나, 다른 겹을 관통해야 하는 정렬은 거부한다.

## 구현

`PaperEdgeAlignment.TryAxis`가 교차하는 두 변의 각 이등분선 또는 평행한 두 변의 중간선을 계산한다.
끝점 순서를 뒤집어도 클릭한 선분 방향을 기준으로 동일한 접는 축을 만든다.
`PaperSheet.Plan`을 통해 선택된 면의 물질 연결, 독립된 겹, 충돌 판정을 그대로 적용한다.
학 도안 단계나 특정 면 번호에 대한 예외는 없다.

`FoldingDesk`의 상태는 Off → Source → Target → Preview → 기존 접기 완료/취소 흐름이다.
완료 시 기존 두 점 조작으로 돌아간다. 회전하여 고른 변이 가려지면 선택을 해제한다.
잘못된 목표선은 종이를 바꾸지 않고 다시 고르게 한다.

## 확인한 결과

- 교차/평행, 네 방향 회전, 각 변의 끝점 순서 반전: 32개 축 계산, 기준선 오차 <0.0001.
- 사용자 유래 6단계 상태에서 앞 07·08 / 뒤 09·10 순서로 변 맞추기: 4회 연속 완료.
- 0~180° 6° 간격, 124개 자세: 면적, 물질 접합, 고정 면 위치 검사 통과.
- 완료된 실제 모서리의 목표선 오차 <0.002(종이 폭 11 기준). 저장 재생 일치.
- 선택 초기화, M/Esc 취소, 카메라를 뒤집어 가려진 변 해제 검사 통과.
- 기존 독립 날개 64개 시퀀스/3,968개 자세, 180° 접기 후 반대 날개 16개,
  제트형 가장자리 8개/368개 자세 회귀 통과. 반대 겹 관통은 계속 차단.

`input.jsonl`은 실제 Input System으로 M, 두 변 클릭, C를 입력한 기록이다.
`preview.png`는 실행 중인 Unity UI 캡처다. `fold-06.json`~`fold-10.json`은 그 조작의 저장본이다.
