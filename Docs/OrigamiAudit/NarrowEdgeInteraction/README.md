# 네 점 가장자리 맞추기 · 2026-11-12

## 조작
1. 접을 가장자리와 목표 중앙선이 만나는 끝점.
2. 접을 바깥 가장자리의 다른 점.
3. F로 점을 추가한 뒤 목표 중앙선 위의 점.
4. 같은 목표 중앙선 위의 다른 점.
5. 면을 클릭하고 C로 밀착 맞추기. 면 드래그로 중간 각도 조절 가능.

이 동작의 1번은 움직일 끝점이 아니라 두 선의 공통점이다. 꽃잎 접기의 네 점 역할과 구분한다. 두 선이 만나는 형태를 지원하며, 떨어진 평행 변의 임의 정렬은 이번 검증 범위가 아니다.

## 변경
- 새 네 점 요청의 separateFoldSides를 가장자리 이등분선 계산에도 전달한다. 기존 저장 기록은 기존 선택 정책을 유지한다.
- 가장자리 맞추기 인식 후 공통점/가장자리/목표선 안내를 표시하고 1·2 교환을 숨긴다. 접기 완료와 선택 취소 시 인식 상태를 해제한다.
- 충돌 및 재질 연결 검사를 유지한다.

## 검증과 범위
- 실제 사용자 상태에서 파생된 두 꽃잎 완료 상태(before.json)에서 Input System 클릭으로 네 점 선택, 면 클릭, C 실행. 접기 6 → 7, 180도 완료(after.json).
- 0~180도 3도 간격 61개 자세: 면적, 모든 재질 연결, 하단 독립 표면의 재질 좌표 유지, 저장 재생, 되돌리기 검사.
- 이 표본의 아래 독립 표면은 접촉 지점에서 확인한 레이어 0/1이다. 다른 연결된 되접힌 조각까지 전부 고정된다고 주장하지 않는다. 원본 사진의 모든 겹 구성이 동일하다고도 가정하지 않는다.
- 기존 WingSide 64개/3968자세, JetEdge 8개/368자세 통과.
- 최초 구현도 이 네 점 예제는 접혔다. 이번 변경은 선택 범위 전달 누락과 조작 안내를 보완한 것이며, 모든 겹침 문제의 해결을 증명한 것은 아니다.
