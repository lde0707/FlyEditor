# 드래곤 연속 접기 — 원인과 해결

## 작업 종료 지점

- 원저자 도안 16번의 교차 접기까지 실제 플레이어 입력으로 접고 다시 폈다. 저장 이력 18회는 도안 18번을 뜻하지 않는다.
- 도안 17번의 여러 접힘을 동시에 모으는 동작은 완성하지 않았다. 이번 수정 뒤 그 동작에 대한 새 검증은 사용자 요청으로 진행하지 않았다.
- 사용자의 실제 게임 저장 데이터는 변경하지 않았다. `evidence/session-e/progress-006.json`은 격리된 검증용 저장본이다.
- 새 오류 탐색과 다음 드래곤 단계는 중지한다.
- 기준: [Jo Nakashima 원저자 도안](https://jonakashima.com.br/wp-content/uploads/2015/07/Dragon-Jo-Nakashima.pdf), [공식 영상](https://www.youtube.com/watch?v=kUsxMXwCW8A). 원본 도안과 영상은 이 폴더에 재배포하지 않는다.

## 1. 연결된 면을 작은 조각 단위로 잘못 판정

**원인:** 접었다 펼친 면에는 이전 절단 조각이 남는다. 분기 접기의 접힘축 검사가 클릭한 조각 하나만 통과해야 한다고 요구해서, 같은 재료가 연속된 이웃 조각을 지나는 선도 거부했다.

**해결:** 같은 공간 평면에서 재료 변환이 일치하고 실제 원본 재료 변을 공유하는 조각만 따라간다. 화면에서 겹친다는 이유로 다른 겹까지 포함하지 않는다. 기존의 단독 날개 분리 검사도 다시 실행했다.

## 2. 짧은 변의 면 안·밖 판정 오차

**원인:** 외적은 면적 단위인데 일정한 거리 오차처럼 사용했다. 변이 짧으면 실제 면 밖의 점도 내부로 인정되어 잘못된 소유권과 가짜 연결 불일치가 생겼다.

**해결:** 변 길이에 비례한 외적 오차를 사용해 실제 거리 기준으로 판정한다. 짧고 긴 변, 종이 회전, 꼭짓점 순서 반전에 대한 최소 회귀 사례를 추가했다. 실제 플레이어 재료 이동은 별도의 와인딩·점과 선분 사이 거리 검사로 확인했다.

## 3. 공유 꼭짓점의 연결 제약 누락

**원인:** 조각의 연결을 공유 선분으로만 판단하면, 여러 접힘선이 만나는 공유 꼭짓점의 제약이 빠질 수 있다.

**해결:** 새 강체 접기에서 원본 종이의 같은 재료 꼭짓점이 접힘축 밖에 있으면 함께 움직여야 하는 연결로 포함한다. 축 위의 점은 그대로 머물 수 있다. 화면에 겹쳐 보이는 서로 다른 재료점을 합치지 않는다. 저장된 예전 동작의 범위를 바꾸지 않도록 새 입력에 `vertexJoints`를 기록한다.

## 4. 작은 절단 조각 누락으로 실제 연결이 벌어짐

**원인:** 절단 결과의 면적이 0.0001 이하이면 유효한 작은 조각도 제거했다. 이동할 작은 조각이 없어지면 원래 면 전체를 고정 면으로 남기는 경로가 있어, 이웃 조각만 움직이며 재료 연결이 벌어졌다. 실제 실패 지점에서는 같은 재료점이 접힘축에서 약 0.00297 떨어져 있는데 한쪽은 이동, 다른 쪽은 고정되어 있었다.

**해결:** 새 강체 입력은 `preserveSlivers`를 저장하고 면적 임계값을 거리 오차의 제곱으로 구분한다. 가까운 원점을 빼고 double 정밀도로 면적을 계산해 작은 면적의 상쇄 오차도 줄였다. 기존 저장본은 예전 절단 순서와 조각 인덱스를 유지한다.

**재검증:** 기존 실패 마우스 입력을 `session-e`에서 다시 실행했다. 대각선 접기, 180도 접힘, 다시 펼치기, 격리 저장까지 수행했다. 실제 이동·고정 재료와 저장 이력의 기하 검사, 원래 상태로의 복귀를 검증했다. 단순히 충돌 검사를 끄거나 최종 메쉬를 교체하지 않았다.

## 기록을 잘못 해석하지 않기 위한 구분

- `session-a`의 맨 아래 끝점 당기기는 공식 영상 확인 전의 잘못된 조작 해석이며 도안 17번의 올바른 재현으로 세지 않는다.
- `session-b/10`은 실제 연결 오류가 확인된 예전 실패 상태다. 통과 사례에서 제외하고 음성 회귀 입력으로 보존했다. 같은 조작의 수정 후 증거는 `session-e`다.
- `session-d`는 3번 명령까지의 선택 수정 증거만 사용한다. 그 이후 실행이 끝나지 않은 입력은 성공이나 제품 오류로 판정하지 않았다.
- 기존 날개 분리, 반대쪽 꽃잎, 접촉 묶음, 연속 접기, 저장 재생 검사는 `logs/regression.log`에 있다. 전체 자유도와 드래곤 완성을 증명하는 검사는 아니다.

새 기능이나 다음 오류 검증은 이어서 진행하지 않는다.
