학 접기 · 한 번 접을 때마다 한 컷

정사각형부터 날개 펼치기까지 실제 Unity 접기 엔진으로 진행한 16회 접기와 시작 화면입니다. 이미지를 누르면 원본을 볼 수 있습니다.

새 변 선택 기능으로 앞뒤 주머니를 펼쳤습니다. 접었다 펴서 자국만 만드는 예비 접기는 생략했습니다. 엔진 재접기와 단계별 캡처이며, 전 과정을 마우스로 조작한 기록은 아닙니다. 변 드래그는 별도 실제 입력 테스트로 확인했습니다.

아직 남은 부분: 도안 13의 몸통 부풀리기는 구현되지 않았습니다. 마지막 이미지는 날개를 펼친 납작한 몸통의 학이며, 도안 전체의 완성 판정은 아닙니다.

원본 이미지는 steps/, 각 단계까지의 접기 데이터는 recipes/에 있습니다. 종이 메시를 그림으로 대체하거나 충돌을 무시하지 않았습니다.
