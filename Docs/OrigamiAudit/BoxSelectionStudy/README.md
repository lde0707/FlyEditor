# V 박스 면 선택 검증 — 2026-11-13

## 사용법
1. 점 두 개로 접는 선을 정한다.
2. V를 눌러 면 선택 모드를 켠다. 클릭은 한 면 선택, 왼쪽 드래그는 박스 선택이다.
3. 기본 [1]은 화면에 실제로 드러난 겹만 고른다. [2] 전체 겹은 박스에 닿은 아랫겹도 포함한다. V 모드 안에서 1/2를 바꿔도 도구는 유지된다.
4. 박스가 접는 선을 넘으면 드래그 시작 쪽을 고른다. 박스를 놓으면 실행 가능한 실제 이동 영역 전체가 초록색으로 표시된다.
5. 다시 드래그해 각도를 조절하고 놓으면 적용된다. Esc는 선택/드래그 취소, Z는 완료된 접기 되돌리기다.

박스는 종이를 사각형으로 잘라내지 않는다. 같은 강체로 연결된 면이 박스 밖으로 이어지면 실제로 움직여야 하는 부분까지 초록색으로 표시한다. 다른 겹을 몰래 끌고 가거나 충돌을 통과시키지 않는다. 선택만으로 불가능한 한 축 접기는 노란색 요청 영역과 제한 안내를 보여준다. 복합 접힘을 새로 생성하는 도구는 아니다.

## 수정
- LayerPress → BoxSelect → 선택 확정/각도 조절의 포인터 FSM. 드래그 동안 화면 밖 이동도 캡처하며 Esc로 취소한다.
- 보이는 겹: 투영 다각형에서 가까운 면의 가림 영역을 차감한다. 중앙점 표본만 쓰지 않아 얇게 노출된 조각도 고른다.
- 실제 source polygon 목록을 FoldStep.selectedFaces에 기록한다. 미리보기와 실제 접기, 저장 재생이 같은 계획을 사용한다.
- 선택하지 않은 접힌 겹이 추가로 필요하면 자동 동반 이동시키지 않는다. 실제 원본 종이의 관절/연결과 기존 충돌 제한을 유지한다.
- Unity JSON의 빈 배열은 기존 선택 방식을 유지한다. 기존 저장의 접기 범위를 바꾸지 않는다.

## 결과
- BoxSelectionVerification: PASS — 42건, 196개 자세. 위/아래 시점, 4회전, 역방향 드래그, 가려진 겹, 얇은 노출, 여러 면, 기울어진 연결 면, 선택 색 면적, 충돌, 면적/이음새, JSON 재생, 취소, 되돌리기.
- 기존 WingSide: PASS — 64개 순서, 3968개 자세 및 16개 180° 날개 접기 순서.
- 실제 플레이 입력: PASS — 3번 접기, 저장된 20개 상태의 재생.
  - session-a: 같은 2겹 종이에서 기본 모드는 윗겹만 26°, 전체 겹은 두 겹을 26° 회전. 기본 모드의 아랫겹 재질 좌표는 고정.
  - session-b: 화면에 보이는 3개 면을 박스 하나로 골라 42° 회전.
- 실제 렌더링 초록 면적과 이동 면적을 비교하고, 독립 재질 좌표 검사로 고정 면/이동 면을 검증했다. 입력 이력은 input.jsonl, 선택/접기 사진은 command-*.png와 full-*.png, 원래 재질/메시는 geometry-*.json, 접기 기록은 recipe-*.json이다.
- 시작 종이는 API로 준비한 공통 회귀용 저장본이다. 빈 종이부터 플레이어 조작으로 모형 전체를 완성했다는 의미는 아니다. 플레이 입력 캡처 후 도움말 문구만 짧게 정리하고 최종 소스로 회귀를 다시 실행했다.
- 사용자의 실제 저장 파일을 덮어쓰지 않았다. 모든 플레이 검사는 별도 임시 진행 파일을 사용했다.

## 재현
격리 Unity 프로젝트에 현재 실제 Assets/_Project/Scripts를 복사한 뒤 실행한다.

- BoxSelectionVerification.Run: 엔진/선택/기존 날개 회귀. 외부 입력 증거 불필요.
- BoxSelectionPlayerVerification.Run: FLYEDITOR_BOX_PLAYER_ROOT를 이 폴더로 지정. 기록된 실제 입력 결과를 검증한다.
- core-final/result.json: 기본 기술 회귀 결과. 전체 고난도 도안이나 모든 연속 접기 경우의 수를 보증하지 않는다.

## 발견하고 해결한 문제
- 기존 V 드래그가 곧바로 첫 면의 각도를 바꿈 → 별도 박스 제스처와 선택 확정으로 분리.
- V를 켜면 전체 겹이 기본 면으로 바뀜 / 범위 전환 시 V가 꺼짐 → 도구 상태와 겹 범위를 분리.
- JSON에서 기존 null 목록이 빈 배열로 읽혀 재생 실패 → 실제 선택 요소가 있을 때만 새 범위를 적용.
- 기울어진 연결 면을 일괄 거부 → 실제 물질 연결을 따라 함께 움직일 수 있게 하고, 고른 면이 계획에서 누락되면 거부.

원래 실패 로그는 box-*-red.log, 최종 검증 로그는 box-delivery.log에 보존했다.
