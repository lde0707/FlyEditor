# 보이는 면 선택과 양쪽 꽃잎 접기 — 2026-11-12

사용자가 저장한 4회 접기 상태를 격리된 Unity 프로젝트에서 복원하고, Input System에 마우스와 키보드 이벤트를 보내 양쪽 꽃잎을 연속으로 접었다. 원본 사용자 저장 파일은 수정하지 않았다. 정사각형부터 새로 접는 검증이 아니라 저장 상태에서 이어 접는 검증이다.

## 선택 규칙
- 기본은 현재 카메라에 보이는 면이다. 접힘을 유지하기 위해 실제로 연결된 면은 함께 움직일 수 있다. 화면에서 겹친다는 이유로 뒤쪽 면을 합치지 않는다.
- 반복 면 클릭으로 숨겨진 다음 겹을 순환하던 동작과 Tab 겹 전환 UI/입력을 제거했다.
- 두 점을 고른 것만으로 특정 겹을 암묵적으로 고정하지 않는다. V는 보이는 면을 명시적으로 다시 고르는 선택사항이다.
- B로 종이를 뒤집으면 점 선택·방향 상태가 초기화된다. 이미 접은 모양과 저장 이력은 유지된다.
- 회전으로 선택한 점이 가려지면 해당 선택을 해제한다. 보이지 않는 면으로 선택을 자동 이전하지 않는다.
- 기본 꽃잎의 네 점에서 1·2가 반대여도 보이는 겹의 실제 자유 끝점이 접힐 수 있으면 그 점을 1 이동점으로 정리한다. 기존 충돌 검사를 통과한 경우만 적용한다.
- 네 점 선택 후 어느 끝점을 잡았는지에 따라 이동점 역할을 바꿔 접을 수 있다. 접기 계획 자체가 불가능한 임의의 네 점을 강제로 접지는 않는다.

## 기본 조작
| 입력 | 동작 |
| --- | --- |
| 점 클릭 / 다시 클릭 | 선택 / 해제 |
| 빈 공간 클릭 | 선택 해제 |
| 2점 선택 → 면 드래그 | 선택 선 기준 접기 |
| F → 양옆 2점 → 끝점 드래그 | 꽃잎·주머니 등 4점 접기 |
| 마우스 놓기 | 현재 접기 적용 |
| B | 종이 뒤집기, 선택 초기화 |
| 우클릭 드래그 | 360도 시점 회전 |
| 휠 / 휠 버튼 드래그 | 확대·축소 / 화면 이동 |
| C (접기 중) | 충돌 허용 범위까지 밀착 |
| R / T / V | 방향 반전 / 1·2 역할 교환 / 보이는 면 다시 선택 |
| ↑↓ / Shift+↑↓ | 1도 / 5도 조절 |
| Backspace / Z | 마지막 점 취소 / 접기 되돌리기 |
| Enter / Esc | 접은 기체 적용 / 현재 선택·접기 취소 또는 닫기 |

기본적인 앞뒤 꽃잎 접기에 T·R·V 전환은 필요하지 않다. 반대쪽은 B로 뒤집고 같은 순서로 진행한다. 조작키는 작업대 하단에 상시 표시하며, 현재 단계의 다음 행동은 우측 설명에 표시한다.

## 검증
- 실제 입력: 앞쪽 75 → 180도, B 뒤집기, 반대쪽 -42 → -114 → -180도. 접기 수 4 → 5 → 6. 두 쪽 모두 1·2를 역순으로 입력했으며 자동 자유 끝점 판별 후 동일한 방향의 드래그로 접었다. T·R·겹 전환 없음.
- VisiblePetalInteractionVerification.Run: 앞뒤 연속 × 2점 순서, 4개 접기 / 148 충돌·형상 자세. 기본 선택, 뒤집기, 움직임 부호, 저장 재생, 숨은 면과 반복 면 선택 8개 위치 검사 통과.
- 기존 검사: 날개 64개 / 3968자세, 밀착 날개 16개, 꽃잎 8개, 주머니 8개, 일반 4점 12개 통과. 충돌·면적·연결과 반대편 보존 검사 유지.
