# 4점 접기 재검증 및 공통 시스템 개선

2026-11-10 · Unity 6000.5.3f1 · 한 변 13점 · 예비 접기 생략

## 결과

물폭탄, 점프 개구리, 종이학, 백합, 드래곤 v2를 현재 엔진으로 다시 접었다. 단순 각도 표본 검사에서 끝내지 않고, 시작 각도부터 연속 이동 → 실제 확정 → 레시피 저장/재생 → 중간 메시 렌더까지 실행했다. **5종 모두 완성하지는 못했다.** 복합 베이스의 목표 모양을 만드는 부분은 아래에 남은 문제로 명시한다.

5종 제작 경로는 엔진 API 시험이다. 별도로 Unity Play Mode에서 실제 InputSystem 마우스/키보드 이벤트로 4점 선택·겹 전환·면/꼭짓점 드래그를 검사했다. 다섯 작품을 마우스로 완주했다는 의미는 아니다.

## 적용한 공통 개선

1. **4점 선택 범위를 유지한다.** 기존에는 4점이라는 이유만으로 전체 겹을 움직이는 경로가 있었다. 이제 네 점을 원래 종이 좌표로 해석해 범위와 겹을 구분한다. 한 면 안에서 고르면 그 면을, 서로 이어진 두 조각에 걸쳐 고르면 해당 연결 영역을 계산한다. 전체 겹은 사용자가 전체 겹 모드를 선택했을 때만 적용한다.
2. **같은 화면 위치의 다른 종이 점을 구분한다.** 종이 두께 때문에 뒤쪽 점이 미세하게 마우스에 가까워 먼저 선택되던 문제를 수정했다. 겹쳐 보이는 점에서는 앞쪽 겹을 우선한다. 겹을 명시적으로 선택한 경우는 그 선택을 따른다.
3. **세 점을 고른 상태에서 겹을 바꿔도 점을 유지한다.** `Tab`으로 다른 겹을 찾아 네 번째 점을 고를 수 있다. 화면상 같은 위치라도 원래 종이의 서로 다른 점이면 같은 점 취소로 처리하지 않는다.
4. **고정된 종이와의 연결을 보호한다.** 자유로운 부채꼴 계산이 고정된 이웃 면과의 경계를 벌리는 경우에는 결과를 거부하고 연결 제약을 고려하는 계산을 시도한다. 충돌 검사를 없애거나 면을 찢어서 도안을 통과시키지 않았다.
5. **맞닿기 직전의 각도를 세밀하게 계산한다.** 큰 입력도 중간 경로를 검사하고, 마지막 막힌 5도 구간을 세분한다. 이번 주머니 시험에서는 -85도 부근에서 멈추는 거친 간격 대신 약 -89.990도로 접근했다. 이것은 접촉 정확도 개선이며, 올바른 주머니 모양 완성과는 별개다.
6. **기존 저장과 구분한다.** 새 레시피의 `regionalPull`에 선택 방식이 저장된다. 기존 레시피는 기본값 false로 기존 경로를 사용한다. 되돌리기와 JSON 재생도 검사했다.

런타임에는 작품 이름, 도안별 좌표, 완성 메시 교체 코드를 넣지 않았다. 도안 좌표는 Editor 진단에만 있다. 접기/선택 입력은 기존 FSM 안에서 수정했다.

표의 횟수는 성공한 도안 단계 수가 아니라 저장된 접기 횟수다. 부분 각도도 확정해서 다음 진단에 남겼다. 물폭탄/백합의 첫 135도 역시 목표 베이스 완성을 뜻하지 않는다. 드래곤 v2의 원문 난이도는 Low-Intermediate이며 다섯 자료 간 통일된 난이도 척도는 없다.

## 검증

- 3가지 점 간격 × 위/아래 겹 × 좌우 점 순서 교환 = 12개 경우에서 1도씩 180도까지 검사.
- 4겹 중 선택한 겹만 접고 나머지 3겹 유지.
- 고정 경계가 있는 부채꼴 반례: 연결을 벌리는 135도 결과를 허용하지 않고 안전한 약 88.701도까지만 진행.
- 원래 종이 면적, 유한 좌표, 공유 경계, 저장 재생의 위치 일치, 되돌리기 검사 통과. 수치 허용 오차는 검증 코드에 명시.
- 실제 마우스/키보드 입력으로 면 드래그, 꼭짓점 드래그, 120도 접기, 세 점 유지 후 Tab 겹 전환, 같은 화면 위치의 다른 네 번째 점 선택, 연결된 면 벌리기, 되돌리기 통과.
- 기존 PaperFoldingVerification도 통과. 이후 앞쪽 점 우선 선택 수정에 대해서는 실제 입력 검사를 재실행했다.
- 성능 벤치마크나 모든 가능한 자기충돌에 대한 보증은 아니다.

## 아직 필요한 공통 엔진 보강

남은 핵심은 **이미 꺾인 여러 면을 동시에 움직이면서, 양옆 접힘의 방향까지 결정하는 것**이다. 현재 방식은 점의 위치와 면 길이를 맞추더라도 종이학의 주머니를 닫는 대신 책장처럼 회전시키는 다른 해를 선택할 수 있다.

- 기존 힌지들의 산/골 방향과 연속적인 각도를 함께 유지하는 다중 힌지 제약이 필요하다.
- 드래그 목표점뿐 아니라 양옆 두 면이 어느 방향으로 돌아가야 하는지도 해에 반영해야 한다.
- 여러 겹의 접촉을 점 단위 차단만으로 판단하지 않고, 실제 움직이는 연결 영역 단위로 다뤄야 한다.
- 이 변경은 물폭탄/백합만을 위한 예외나 강제 메시 변형으로 처리하면 안 된다. 같은 공유 경계·면적·겹 유지 검사를 통과해야 한다.

이 부분은 이번 적용에서 해결했다고 주장하지 않는다. 예비 접기를 다시 요구하는 방식으로 우회하지 않았다.
