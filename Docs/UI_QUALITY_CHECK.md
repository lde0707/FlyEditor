# UI 화질 확인 — 2026-11-05

## 확인한 원인

원본 Unity Game 뷰에서 Free Aspect와 **Low Resolution Aspect Ratios**가 켜져 있었다. 배율은 약 1.3x로 표시되어 낮은 해상도로 렌더링한 화면을 확대하고 있었다. 흰 배경의 얇은 선과 작은 글자가 특히 거칠게 보였다.

## 적용한 설정

- Game 뷰 해상도 메뉴의 Low Resolution Aspect Ratios 해제.
- Full HD (1920×1080) 선택.
- 확대 Game 뷰와 Scale 1x에서 글꼴·심볼·연결선을 비교.
- 확인 후 전체 UI를 볼 수 있는 맞춤 배율로 복귀.

저해상도 옵션을 끄자 배율 표시가 1x로 바뀌며 작은 글자가 선명해지는 것을 직접 확인했다. Full HD / 1x에서도 연구 이름·효과·비용과 심볼을 확인했다. 실제 PNG 임포트는 압축 없음·Bilinear·Mipmap Off였고 PC URP Render Scale은 1이었다.

## 구분할 점

Game 뷰가 1920×1080보다 작으면 전체를 보여주기 위해 축소한다. 이때 얇은 선과 작은 글자는 1x보다 덜 선명해질 수 있다. 확대/축소된 미리보기의 부드러움과 이미지 파일 자체의 손상을 구분한다.

이번에는 에디터 미리보기 설정을 수정했다. 런타임 UI 코드, 비행·구매·저장 로직, 사용자 연구점은 변경하지 않았다. 재컴파일이나 게임 모델 회귀 검사 대신 실제 표시 설정과 화면을 비교했다.

다시 확인할 때: Game 해상도 메뉴 → Full HD, Low Resolution Aspect Ratios 꺼짐 → 화질 비교 시 Scale 1x. 전체를 보고 싶으면 Game 탭 우클릭 → Maximize 또는 맞춤 배율을 사용한다.
