# FlyEditor 파스텔 민트 선택·강화 상태 v2

검정 채움을 제거하고 낮은 채도의 파스텔 민트로 변경했다. 흰 배경, 각진 형태, 이중 선택 테두리, 체크와 단계 표시를 유지한다.

| 상태 | 표현 |
|---|---|
| 후보 | 흰 바탕·짙은 회녹색 윤곽선 |
| 선택 | 차분한 민트 계열 이중 테두리 |
| 강화 1단계 | 아주 연한 민트 바탕 + 체크 + 단계 1칸 |
| 강화 2단계 | 연한 민트 바탕 + 체크 + 단계 2칸 |
| 최대 3단계 | 조금 더 진한 파스텔 민트 + 짙은 녹색 심볼 + 단계 3칸 |
| 구매 버튼 | 파스텔 민트 면색 + 짙은 녹색 글자 |

색상: 선택선 #527A65, 글자/체크 #304F3F, 1단계 #F0F6F2, 2단계 #DCEBE2, 3단계 #BED9C9. 발광·그라데이션은 없다.

PNG 49개와 동일한 SVG 원본 49개를 제공한다. 프레임 18개, 현재 기본 연구 3종의 단계·선택 조합 24개, 구매 연출 오버레이 3개, 설명창 구매 버튼 4개다. 이름은 이전 흑백 상태 에셋과 같고 새 폴더 및 별도 GUID로 구분한다.

노드 완성형은 160×192, 버튼은 512×96이다. 버튼은 14px border로 Image Type=Sliced, 노드는 Image Type=Simple을 사용한다. PNG는 투명 배경이며 버튼 문구는 Unity 텍스트로 별도 표시한다. 민트 버튼 위 텍스트에는 #304F3F를 사용한다.

Unity 위치: Assets/_Project/UI/ResearchUI_States_Mint_v2. 기존 흑백 에셋은 보존했다. 실제 버튼 상태 변경 코드는 수정하지 않았다.

Previews/Selection_Upgrade_States.png에서 전체 상태를 비교할 수 있다. build_states.py는 기존 research-ui-v1 폴더의 벡터 아이콘을 확장한다. 재실행 시 두 폴더를 같은 부모 경로에 둔다.
